# Test videos: where each one comes from

Only the tables clip is a stock video from Mixkit; the others are from YouTube, chosen by the page owner (see their rows): doorway, counter and shelf are shop camera samples, walkway is a street filmed from the pavement. The Mixkit clip is one (mixkit.co, run by Envato) whose own page offers it
"for commercial or personal use, under the Mixkit Stock Video Free License". Clips that Mixkit
marks "for personal use only" (its Restricted License) are not used. Mixkit's pages name no
author. Each clip was re-encoded smaller with no sound (by `scripts/fetch-videos.sh`, or by hand with the same settings); nothing else
was changed unless the row says so. Licence wording read on each clip's page on Fri 20 Nov 2026.
